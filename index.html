Professional Self-Assessment

This capstone project and ePortfolio helped demonstrate my ability to code and connect to a database.

Being able to effectively connect the front end to the backend is essential in coding. The use of python

to help create a program to assist in data analysis was also important in demonstrating my skills.

The use of handlebars rather than normal html showed how I can use different tools to create code.

When it comes to computer science many talents are needed. Working within a team, talking with stakeholders,

using data structures and algorithms, software engineering and databases, and finally security.

Some of these skills involve talking to others and some of these skills are about the code itself.

In the world of computer science working with others and clearly communicating with others is extremely

impportant. Coding is obviously important within computer science, being able to code and use data bases

is a big part of what computer scientist need to do. The point of this capstone was to demonstrate

as many of these skills as possible which is what I attempted to do.
